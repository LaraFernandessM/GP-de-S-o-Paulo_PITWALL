# 🏁 PIT WALL — GP de São Paulo

Projeto desenvolvido para o desafio de Linguagem de Marcação (LIMA), com o objetivo de recriar uma página inspirada no Grande Prêmio de São Paulo de Fórmula 1, utilizando HTML e CSS.

## 📌 Sobre o projeto

O Pit Wall é uma página temática de Fórmula 1 que apresenta informações sobre o GP de São Paulo, incluindo grid de pilotos, classificação e formulário de ingressos.

O projeto foi desenvolvido para praticar conceitos de desenvolvimento front-end, estilização e responsividade.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts — Titillium Web

## 🏎️ Funcionalidades

- Página inicial temática do GP de São Paulo
- Cards dos pilotos e suas equipes
- Tabela de classificação
- Formulário de reserva de ingressos
- Seção de preços dos setores
- Efeitos de hover
- Layout responsivo para computadores e celulares
- Background com imagem de corrida
- Zebra decorativa inspirada na pista
